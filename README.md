# 🏠 Hostel Visitor Management System

A web application built with Python and Flask to manage hostel visitor entries.  
Guards can log visitor details, track IN/OUT time, and admins can monitor all activity.

## 🔗 Live Demo
[Click here to visit](http://Shivamwadje22.pythonanywhere.com)

## 📋 Features
- **Secure Login** - Admin and User roles with password hashing
- **Visitor Entry** - Add new visitor with name, student name, room no, purpose
- **IN/OUT Tracking** - Mark visitor as OUT with timestamp
- **Visitor Log** - View all past and current visitors in a table
- **Dashboard** - Quick overview of total and current visitors
- **Responsive Design** - Works on mobile, tablet and desktop
- **Deployed** - Live on PythonAnywhere

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** HTML, CSS, Bootstrap 5
- **Authentication:** Werkzeug Security
- **Deployment:** PythonAnywhere
- **Version Control:** Git & GitHub
